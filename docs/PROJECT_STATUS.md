# 工程状态

更新时间：2026-06-11

## 当前状态

- 主入口：`fund_platform.py`
- 界面形态：Python / Tkinter 桌面程序
- 数据存储：本地 JSON、Excel、SQLite 缓存
- 开源范围：只上传代码、文档、运行脚本和目录占位说明，不上传真实数据、缓存、日志和评分结果

## 已完成

- 原基金筛选系统与可视化系统合并为单文件主程序。
- 点击收益表现、风险回撤、风险效率、位置估值等模块后，在软件内部展示同花顺风格看板。
- 基金详情页支持净值走势区间切换、回撤指标叠加、拖拽十字线查看日期和净值。
- 基金对比支持多只基金加入对比池后统一展示走势。
- 首页加入全球市场、资金流向和我的持仓入口。
- 一键运行支持模块预计算，后续点击优先读取缓存。
- 日常爬取采用迭代模式，保留历史净值，只补最新净值。
- 收益表现和风险回撤支持流式计算，减少内存占用。
- 大体积基金 JSON 生成 SQLite 索引，详情、走势、对比和持仓按代码读取。
- 模块重计算通过独立 Python 子进程执行，主界面可以继续操作。
- 模块按钮支持后台并发，默认最多 2 个任务，可通过 `FUND_MODULE_WORKERS` 调整。
- 结果表格分批渲染，净值走势图降采样绘制。
- 结果窗口不再强制置顶或抢焦点。

## 运行时生成目录

- `fund_data/`：基金 JSON 数据
- `fund_excel/`：模块评分和专题筛选结果
- `fund_cache/`：模块缓存、资金流缓存、SQLite 索引
- `fund_visual_reports/`：历史报告
- `target_funds.json`：清洗后的基金池
- `my_portfolio.json`：我的持仓
- `watchlist_funds.json`：自选基金

这些文件默认不提交到 GitHub。
